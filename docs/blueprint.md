# **App Name**: myLunaraCycle

## Core Features:

- Dynamic Calendar View: Display cycle days, ovulation, pregnancy weeks/trimesters and moon phases in a calendar view using NASA data.
- Secure Multi-Language Login: Allow the user to log in using a password or Google account and switch between German and English.
- Mood & Journal: Mood tracker with emojis to record daily moods and password-protected journal entries.
- Affirmation Generation: AI tool that uses user data to generate daily motivational quotes tailored for the user's mode and journal entries.
- Mode Toggle: Display a toggleable sidebar for switching between 'Zyklusmodus' and 'Schwangerschaftsmodus'.
- Reminder System: Configure personalized reminders based on user selected mode such as period due or pregnancy support messages.

## Style Guidelines:

- Soft purple (#D0B8E8), used for buttons and progress bars to evoke femininity and balance.

- Clean, sans-serif fonts that ensure readability, to match a modern design.
- Custom icons with rounded edges and a handcrafted aesthetic for a personal and gentle touch.
