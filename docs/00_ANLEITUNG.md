## Warum diese Reihenfolge existiert

Lovable baut deinen Code Schritt für Schritt auf.
Wenn du die Reihenfolge ignorierst, bekommst du Chaos.

Das ist kein Vibe Coding. Das ist strukturiertes Aufbauen mit AI-Unterstützung.

## Die 7 Phasen — Reihenfolge ist heilig

```
PHASE 1 → Projekt Setup & Supabase
PHASE 2 → Datenbankstruktur (Schema)
PHASE 3 → Authentication
PHASE 4 → Core Logic (Zyklusberechnung + Mondphasen)
PHASE 5 → UI Screens
PHASE 6 → Spirituelle Inhalte & i18n
```

**Niemals Phase 5 vor Phase 4 starten.**
**Niemals Phase 3 überspringen.**
**Immer nach jeder Phase testen, bevor du weitermachst.**

## Anti-Chaos Regeln für Lovable

1. **Ein Prompt = Eine Aufgabe.** Nicht alles auf einmal fragen.
2. **Nach jedem Prompt: testen.** Klick durch die App bevor du weiter machst.
3. **Fehlermeldungen immer komplett kopieren.** Nicht zusammenfassen.
4. **Niemals sagen "mach es schöner".** Immer spezifisch sein.
5. **Bei Bugs: den exakten Screen + exakten Bug beschreiben.**
6. **Kein "Accept All" blind.** Schau dir an was sich geändert hat.
